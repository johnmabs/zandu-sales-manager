# 14. Epic F0.7 — UI primitives

Créer :

```text
packages/ui
```

Composants de base :

```text
Button
IconButton
Input
Textarea
Select
Checkbox
Radio
Dialog
Drawer
DropdownMenu
Tooltip
Badge
Alert
Toast
Spinner
Skeleton
EmptyState
ErrorState
Pagination primitives
```

Ces composants ne connaissent pas :

```text
Product
Sale
Stock
Supplier
```

Ils restent génériques.
